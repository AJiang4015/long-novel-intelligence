# V0.2.4-b RC3：RELATIONAL_GENERIC 词表 — 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复 RC3——relational generic 词（兄弟/哥哥/弟弟/儿子/女儿/妇人等）通过 hygiene.py 精确词表归入 GENERIC，永不成为 canonical，但保留 alias mention 能力（有候选进 judge、无候选丢弃）。祖父/父亲/母亲不进词表（正文真实人物）。

**Architecture:** hygiene.py 新增 `_RELATIONAL_GENERIC_WORDS` 精确词集合，`classify_mention` 命中返回 `MentionCategory.GENERIC`；resolver `_resolve_name` 将「hygiene 判定 GENERIC」纳入决策（与 LLM category 的 GENERIC 同等对待）；GENERIC 语义复用现有逻辑（无候选丢弃 + generic_filtered 计数、有候选 judge）。不改 MentionCategory Enum。

**Tech Stack:** Python 3.x + pydantic（现有），无新依赖。

## Global Constraints

- 只改 `backend/app/pipeline/hygiene.py`、`backend/app/pipeline/resolver.py`、`backend/tests/unit/test_hygiene.py`
- **MentionCategory 仍为 6 类**，不新增 RELATIONAL_GENERIC Enum
- **精确词匹配**：`name in _RELATIONAL_GENERIC_WORDS`，**不做子串模糊匹配**（避免误伤「顺顺的兄弟」等描述性 mention）
- **祖父/父亲/母亲不进词表**（《边城》真实人物，PERSON 正常注册）
- GENERIC 语义：有候选 → alias judge（true→alias，null→丢弃）；无候选 → 丢弃；**永不新建 canonical**
- **generic_filtered 只统计最终因 GENERIC 无候选被丢弃的 mention**；成功 alias 的 GENERIC 不计入
- 不修改 RC2 已冻结代码、不修改 canonical merge bridge、不处理 ReadTimeout、不迁移 Neo4j、不新增 chapter skip
- 测试命令统一 `cd backend && python -m pytest ...`

```python
# V0.2.4-b RC3：relational generic 精确词表（归入 GENERIC，不新增 Enum）。
# 只限制「建立 canonical 的资格」：有候选可 alias，无候选丢弃，永不新建 canonical。
# 精确词匹配（name in set），不做子串匹配，避免误伤「顺顺的兄弟」等描述性 mention。
# 祖父/父亲/母亲 不进词表——它们是《边城》正文真实人物。
_RELATIONAL_GENERIC_WORDS = {
    "兄弟", "哥哥", "弟弟", "姐姐", "妹妹", "儿子", "女儿",
    "妻子", "丈夫", "祖母", "外婆", "外公", "叔叔", "婶婶", "侄儿", "侄女",
}
```

修改 `classify_mention` 返回逻辑（在 COLLECTIVE 检查之后、return None 之前）：

```python
    for pat in _COLLECTIVE_PATTERNS:
        if pat.match(name):
            return MentionCategory.COLLECTIVE
    # V0.2.4-b RC3：relational generic 精确词 → GENERIC（有候选可 alias，无候选丢弃）
    if name in _RELATIONAL_GENERIC_WORDS:
        return MentionCategory.GENERIC
    return None
```

**注意**：`is_hard_filtered` 仍只返回 COLLECTIVE/INVALID——GENERIC 不进硬过滤（符合语义）。
