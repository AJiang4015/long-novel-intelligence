## 1. 背景与问题（RC3）

Job 880c9f1c 诊断：`兄弟` 在 ch2 题记（作者沈从文自述「我的祖父，父亲，以及兄弟，全列身军籍」）被 extractor 输出为 character → 当前 hygiene `classify=None` → category fallback=PERSON → **ch2 注册为 canonical** → 正文 ch6/13 中 天保/傩送/大儿子/二老 同 chunk 共现 → alias judge 吸入 `兄弟` canonical → P09 第二条污染链。

## 3. Problem Boundary

RC3 ≠ 简单的「词表删除」。`祖父`/`父亲`/`母亲` 是《边城》**正文真实人物**（ch4 首现即指代、高频），必须保留 canonical 资格；`兄弟` 污染来自**题记（元文本）语境**。必须区分：

1. **canonical 建立资格**（哪些可注册为 canonical）
2. **alias mention 资格**（哪些可作为 mention 参与消歧）

## 5. 设计

### 5.1 hygiene.py 词表（精确词匹配，归入 GENERIC）

```python
# V0.2.4-b RC3：relational generic 精确词表（归入 GENERIC，不新增 Enum）。
# 只限制「建立 canonical 的资格」：有候选可 alias，无候选丢弃，永不新建 canonical。
# 精确词匹配（name in set），不做子串匹配，避免误伤「顺顺的兄弟」等描述性 mention。
# 注意：祖父/父亲/母亲 暂不进入本词表，是基于《边城》当前数据验证（正文真实人物）的
# **项目级决策，不是通用语义规则**——换小说时需重新评估这些词是否该入表。
_RELATIONAL_GENERIC_WORDS = {
    "兄弟", "哥哥", "弟弟", "姐姐", "妹妹", "儿子", "女儿",
    "妻子", "丈夫", "祖母", "外婆", "外公", "叔叔", "婶婶", "侄儿", "侄女",
}
```

`classify_mention`：COLLECTIVE/INVALID 检查后，`if name in _RELATIONAL_GENERIC_WORDS: return MentionCategory.GENERIC`。

**不改**：MentionCategory Enum（6 类）、COLLECTIVE/INVALID 模式、`is_hard_filtered`（GENERIC 不进硬过滤）。

### 5.2 resolver category precedence（评审锁定 2026-08-23）

明确优先级——**relational-generic exact-match 高于 LLM category**：

```
1. COLLECTIVE / INVALID hard rules（is_hard_filtered 分支）
2. relational-generic exact-match → 强制 GENERIC（无论 LLM category 是 PERSON/None/其他，
   都不得注册为 canonical）
3. 其余才使用 LLM category
4. 无 category 才走 legacy PERSON fallback
```

```python
candidates = self._recall(name, confirmed, text_confirmed)
from app.pipeline.hygiene import classify_mention
hy_cat = classify_mention(name)
if hy_cat == MentionCategory.GENERIC:
    cat = MentionCategory.GENERIC   # 强制覆盖 LLM category（含 LLM 误标 PERSON）
else:
    cat = self._category_of(name)   # LLM category（可能 None → legacy PERSON）
```

### 5.3 GENERIC 语义（复用现有，不变）

- 永不新建 canonical
- 有候选 → alias judge（judge=true → alias；judge=null → 丢弃）
- 无候选 → 丢弃（`generic_filtered += 1`）
- **generic_filtered 只统计最终因无候选被丢弃的**；成功 alias 不计入

### 5.4 明确不做

- ❌ 不新增 RELATIONAL_GENERIC Enum（MentionCategory 6 类不变）
- ❌ 不新增「前 3 章跳过」规则（无证据支持，且会误伤 ch3 专名 兆和）
- ❌ 不把 祖父/父亲/母亲 加入词表（正文真实人物，项目级决策）
- ❌ 不修改 RC2 已冻结代码 / canonical merge bridge / ReadTimeout / Neo4j 迁移 / Group
