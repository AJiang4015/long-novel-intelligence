Design System · 长篇小说人物关系分析

专业、克制、数据优先的分析工作台视觉语言

面向"人物关系图谱"单页工作台的组件与令牌规范。强调信息密度与层级、长时间使用的舒适度，以及关系图作为核心内容的表现力。所有令牌直接映射 V0.1 API 数据模型（JobResponse / CharacterCandidate / GraphResponse / Evidence），不引入新业务概念。

桌面端优先 React 19 · TypeScript react-force-graph-2d 浅色主题

Principles

四条设计原则

数据优先

关系图、数字与证据是主角；界面后退一步，用发丝线与留白组织信息，不用装饰抢内容。

克制一致

单一强调色、受限的圆角与阴影层级、统一的 4pt 间距网格，让长会话中的注意力集中在变化上。

层级即语义

中心人物、一跳邻居、关系类型、证据详情的视觉层级一一对应它们在数据模型中的位置，不靠颜色玄学。

可读可扫

等宽数字、tabular-nums、明确的标题层级与证据长文排版，兼顾扫读与精读两种场景。

Graph · 06

关系图视觉规范

关系图是工作台的核心：中心人物 > 一跳邻居 > 关系边 的层级由视觉重量显式表达；节点大小映射 mention_count，边用颜色 + 线型 + 标签三重编码。

节点样式

中心人物
品牌绿实心 + 白色描边 + 柔和外环；名称加粗置于节点下方，永远是图中最重的元素。
一跳邻居
白底灰描边；半径按提及数在 8–18px 间缩放；悬停描边转品牌绿、名称转深色。
悬停 / 可点击
描边转品牌绿并外扩柔环，提示可点击切换为中心人物；轻投影提升层级。
